# Admin User Guide (no developer needed)

Sign in at **/admin**. The sidebar only shows modules your role may use.

## Add a vehicle
Vehicles → **Add vehicle**. Fill title, brand, price, year (required). Pick a model or type a new one. Click **Add photos** to upload or choose from the library; the **first photo is the featured image** — reorder with the arrows or “Set featured”. Tick features, add extra specs, fill the optional Pakistan fields (auction grade, verified mileage, token tax…), then tick **Published** and Save.
Row menu (⋯) in the list: publish/unpublish, feature, mark available/reserved/sold, **duplicate** (creates an unpublished copy), delete.

## Brands, categories, features
Inventory → Brands / Categories / Features: add, edit, disable (hides on the site) or delete. A brand that still has vehicles cannot be deleted — disable it or move its vehicles first. Use arrows to change display order.

## Change the homepage
Website → **Homepage sections**. Each row is a section (hero, search bar, featured, latest, brands, categories, why-us, about, testimonials, news, newsletter, custom text, call-to-action). Use ↑/↓ to reorder, the eye-status (edit → *Visible*) to hide, ✎ to edit headline/images/buttons, **Add section** for new ones (you can add several custom text or call-to-action blocks), 🗑 to remove.
Change the hero background: edit the Hero section → *Background image*.

## Pages, blog, FAQs, testimonials, navigation
- **Pages**: edit About, Services, Financing, Privacy, Terms or **Add page** (it appears at `/your-slug`; tick “Show link in footer” to list it). Content is simple HTML: `<h2>`, `<p>`, `<ul><li>`, `<a href>`, `<img src>`.
- **Blog**: write posts; tick Published to show them. **FAQs/Testimonials**: add, reorder, publish.
- **Navigation**: add/hide/reorder header and footer links.

## Leads (CRM)
Sales → Leads: search, filter by status/type/assignee, **Export CSV**. Click a lead to change status (New → Contacted → Follow-up → Interested → Negotiation → Converted/Lost), assign staff, add internal notes, see every inquiry from that customer, call or WhatsApp them in one click. Test-drive requests appear in **Test drives** (Approve/Reject/Complete + notes) and also create a lead.

## Media library
Website → Media library: upload (auto-optimised), search, edit alt text (good for SEO), copy URL, delete.

## Settings
Settings: site name, logo, favicon, colours, phone, **WhatsApp number** (used by every WhatsApp button), email, address, hours, Google Maps embed URL, currency, cities list, social links, SEO defaults, **Maintenance mode** (visitors see a notice; logged-in staff still see the site).

## Users & roles (Super Admin)
Users & roles → Add user, choose role, set a password (≥ 10 chars). Deactivate to block login instantly. The last Super Admin cannot be removed or demoted. **Activity log** shows who changed what.
